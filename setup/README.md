## Setup

Open your Terminal application and navigate to your <code class="filepath">~/code/ga/labs</code> directory:

```bash
cd ~/code/ga/labs
```

### Create and clone a GitHub repo

Make a new repository on [GitHub](https://github.com/) named `update-your-computer-lab`.

Clone a copy of your remote repo locally by using the `git clone` command:

```bash
git clone https://github.com/<your-username>/update-your-computer-lab.git
```

Replace `<your-username>` (including the `<` and `>`) with your GitHub username before you run this command.

### Launch in VS Code

Next, `cd` into the cloned directory, <code class="filepath">update-your-computer-lab</code>:

```bash
cd update-your-computer-lab
```

Create a <code class="filepath">README.md</code> file in this directory:

```bash
touch README.md
```

Open the contents of the directory in VS Code:

```bash
code .
```

Open the <code class="filepath">README.md</code> file in VS Code and add the following content to it:

```markdown
# Update Your Computer Lab

## Operating system



## OS version at the start of the lab



## Were you able to install any updates for your system?



## OS version at the end of the lab



## Wrap up

```

Add the name of your operating system (for example, Windows, macOS, or Ubuntu) to the **Operating System** section.
