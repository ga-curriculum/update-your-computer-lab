## Lab requirements

The following requirements describe the functionality that should be present in the lab, and the points awarded out of 100 for each piece of functionality.

| Criteria                                                                                                                                                                                                                | Points |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| The <code class="filepath">README.md</code> file contains the name of the operating system on your device.                                                                                                              | 20     |
| The <code class="filepath">README.md</code> file contains the version of your operating system at the start of the lab.                                                                                                 | 20     |
| The <code class="filepath">README.md</code> file indicates if you were able to install any updates for your system as part of this lab.                                                                                 | 20     |
| The <code class="filepath">README.md</code> file contains the version of your operating system at the conclusion of the lab.                                                                                            | 20     |
| The <code class="filepath">README.md</code> file contains information about how the update process went for your, including if you were unable to install any updates and how long the update process took to complete. | 20     |
| **Total possible points**                                                                                                                                                                                               | 100    |
